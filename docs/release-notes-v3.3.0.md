# Release Notes: v3.3.0

## Summary

Version 3.3.0 introduces Story Map, a visual planning canvas alongside the manuscript.

## Highlights

### Story Map

- Opens in its own window and saves scenes, notes, chapters, arcs, and canvas views with the novel.
- Add and position scenes, set chronology relative to the start of the story using signed Day and Year values, and edit location, characters, free-text tension, and notes.
- Assign scenes to the novel's chapter list, with chapter colors and chapter-based layout.
- Switch between sequential and temporal views, including split timelines and character/POV lanes.
- Create arcs prospectively or from selected scenes; assign scenes to multiple arcs and switch thread ordering between narrative and chronological modes.
- Manage arcs by renaming, recoloring, merging, splitting, and deleting. Arc threads support hover-to-focus.
- Link scene notes to wiki pages, with navigation to the wiki pane in the main window.
- Canvas colors and controls follow the application's light/dark theme.
