UX Design for Netwriter
======================

This folder contains the initial UX deliverables for the Netwriter macOS MVP:

- style-guide.md — color palette, typography, spacing, and tokens
- components.md — list of core components and behaviors
- prototype/ — minimal HTML/CSS prototype demonstrating the manuscript (3/4) / sidebar (1/4) layout

Open `prototype/mockup.html` in a browser to view the interactive layout prototype.

Next steps:
- Review and confirm palette/typography choices
- Request higher-fidelity mockups (Figma/Sketch) or design tokens export
- I can also generate React/Electron-ready components if you'd like to implement the UI directly.
